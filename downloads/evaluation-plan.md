## วิธีใช้

- ชื่อโครงการ / เจ้าภาพ / ระยะเวลา: …
- ปัญหาและหลักฐานตั้งต้น: …
- ผู้ใช้ผลและการตัดสินใจที่จะใช้: …
- กลุ่มเป้าหมาย / ขอบเขต / ผู้ที่อาจถูกตกหล่น: …
- เส้นทางจากกิจกรรมสู่ผลลัพธ์และสมมติฐาน: …
