# เกณฑ์บรรยายคุณภาพการส่งต่อ

ต้นแบบเพื่อปรับใช้ · อยุธยาเรียนรู้ SDG 4 · 15 กันยายน 2569

## วิธีใช้
ต้นแบบสำหรับพัฒนา ไม่ใช่เกณฑ์ราชการ ให้ผู้เกี่ยวข้องตกลงนิยาม “บริการ” “ทันเวลา” และหลักฐานที่ใช้ก่อนทดลอง ให้ผู้ประเมินสองคนตรวจกรณีเดียวกันอย่างอิสระแล้วหารือจุดต่าง ไม่สร้างคะแนนรวมเมื่อยังไม่ตรวจคุณภาพเกณฑ์

| ระดับ | คำบรรยายหลักฐาน |
|---|---|
| ยังประเมินไม่ได้ | หลักฐานขาดจนไม่ทราบสถานะ ต้องติดตามเพิ่ม ไม่ให้เป็นศูนย์ |
| เริ่มดำเนินการ | มีคำขอส่งต่อ แต่ยังไม่ยืนยันปลายทางรับช่วง |
| รับช่วงแล้ว | ปลายทางรับเรื่องและมีผู้รับผิดชอบ แต่ยังไม่ยืนยันบริการ |
| ได้รับบริการ | ยืนยันว่าผู้เรียนได้รับบริการตามความจำเป็นและเวลาที่ตกลง |
| ติดตามและปรับบริการ | ตรวจผลหลังบริการ รับฟังผู้เรียน และปรับเมื่อมีอุปสรรค |

| รหัสกรณีที่ไม่ระบุตัวตน | ระดับผู้ประเมิน ก | ระดับผู้ประเมิน ข | หลักฐาน / จุดต่าง | ข้อสรุปและเหตุผล |
