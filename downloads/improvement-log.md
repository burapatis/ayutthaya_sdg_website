# แบบสรุปผลและแผนปรับปรุง

ต้นแบบเพื่อปรับใช้ · อยุธยาเรียนรู้ SDG 4 · 15 กันยายน 2569

## สรุปผลหนึ่งรอบ
- โครงการ / รอบข้อมูล / ผู้จัดทำ: …
- คำถามที่ประเมิน: …
- ค่าฐาน / เป้าหมาย / เกณฑ์และหลักฐานรับรอง: …
- ผลที่พบ / ตัวตั้ง / ตัวหาร / ความครบถ้วน: …
- ข้อจำกัดและสิ่งที่ยังสรุปไม่ได้: …
- มุมมองผู้เรียนและภาคี: …
- ผลที่ไม่คาดคิดและกลุ่มที่ยังเข้าไม่ถึง: …

|---|---|---|---|---|---|---|
| … | … | … | … | … | … | รอติดตาม |

สถานะควรแยก “รอข้อมูล / อยู่ระหว่างทำ / ทำแล้วรอตรวจผล / ตรวจผลแล้ว” การส่งเอกสารไม่เท่ากับการแก้ปัญหาสำเร็จ ให้ปิดประเด็นเมื่อมีหลักฐานตามที่ตกลง
