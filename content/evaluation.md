## วัดเพื่อเข้าใจและปรับปรุงการศึกษา

การติดตามบอกว่างานดำเนินไปอย่างไร การวัดผลทำให้เห็นค่าหรือระดับตามนิยาม ส่วนการประเมินใช้หลักฐานตอบคำถามว่าผลนั้นมีคุณค่า เหมาะสม และควรปรับอย่างไร หน้านี้เสนอกรอบและเครื่องมือสำหรับหารือร่วมกัน ไม่ใช่เกณฑ์รับรองคุณภาพของทางราชการ

### 1. เริ่มจากคำถามที่ต้องใช้ตัดสินใจ

กำหนดก่อนว่าใครจะใช้ผลประเมิน ตัดสินใจเรื่องใด และเมื่อใด ตัวอย่างเช่น “ผู้เรียนที่ย้ายได้รับการรับช่วงดูแลจริงหรือไม่” ตอบโจทย์การแก้รอยต่อได้ตรงกว่าการถามเพียง “ส่งหนังสือครบหรือไม่” แล้วจึงเลือกตัวชี้วัดและเครื่องมือให้ตอบคำถามนั้น

| ระดับผล | ตัวอย่างโครงการพัฒนาครูด้านการอ่าน | หลักฐานที่เหมาะสม |
|---|---|---|
| ทรัพยากร | เวลา บุคลากร สื่อ และงบที่ใช้ | บันทึกต้นทุนและทรัพยากรจริง |
| กระบวนการ | การชี้แนะและทดลองสอนตามแผน | บันทึกการชี้แนะและสังเกตชั้นเรียน |
| ผลผลิต | ครูเข้าร่วมและมีแผนช่วยผู้เรียน | จำนวนคนไม่ซ้ำและแผนที่ตรวจคุณภาพ |
| ผลลัพธ์ | ครูใช้แนวทางได้ ผู้เรียนอ่านดีขึ้น | ผลงานและคะแนนที่เปรียบเทียบได้ พร้อมข้อมูลผู้ขาดการติดตาม |
| ผลกระทบ | คุณภาพและความเสมอภาคดีขึ้นต่อเนื่อง | หลักฐานระยะยาวและวิธีวิเคราะห์ปัจจัยอื่นร่วมด้วย |

จำนวนกิจกรรมและผู้เข้าร่วมมีประโยชน์ต่อการติดตามการส่งมอบ แต่ยังไม่เพียงพอที่จะตอบผลการเรียนรู้ ส่วนการเปลี่ยนแปลงระยะยาวไม่ควรถูกอ้างว่าเกิดจากโครงการเดียวหากยังไม่มีวิธีตรวจสอบสาเหตุ

### 2. กระบวนการประเมินแปดขั้น

1. **กำหนดคำถามและผู้ใช้ผล:** เลือกการตัดสินใจที่สำคัญ และให้ผู้เรียนหรือผู้ได้รับผลกระทบมีส่วนร่วม
2. **ทำแผนผังผลที่คาดหวัง:** ระบุว่ากิจกรรมจะนำไปสู่ผลใด ภายใต้สมมติฐานและเงื่อนไขอะไร
3. **กำหนดนิยามและค่าฐาน:** ระบุประชากร วันนับ ตัวตั้ง ตัวหาร แหล่งข้อมูล และผู้รับรองก่อนตั้งเป้า
4. **เลือกวิธีและทดลองเครื่องมือ:** ตรวจเนื้อหา ภาษา การเข้าถึง และวิธีให้คะแนนกับกลุ่มขนาดเหมาะสมก่อนใช้งาน
5. **เก็บข้อมูลอย่างเป็นระบบ:** ใช้แบบเดียวกัน ระบุรอบข้อมูล ป้องกันนับซ้ำ และบันทึกผู้ที่ติดตามไม่ครบ
6. **ตรวจและวิเคราะห์:** ตรวจค่าผิดช่วง ความครบถ้วน และความต่างของกลุ่ม ใช้ข้อมูลหลายวิธีประกอบกัน
7. **ตีความและรายงาน:** แยกข้อค้นพบ ข้อจำกัด คำอธิบายที่ยังเป็นสมมติฐาน และข้อเสนอ ไม่ซ่อนผลที่ไม่ถึงเป้า
8. **ปรับปรุงและติดตามซ้ำ:** ระบุสิ่งที่จะเปลี่ยน เจ้าภาพ กำหนดเวลา และหลักฐานที่ใช้ยืนยันผลหลังปรับ

### 3. เลือกวิธีให้ตรงคำถาม

| วิธี | เหมาะกับคำถาม | ข้อจำกัดที่ต้องรายงาน |
|---|---|---|
| ข้อมูลทะเบียนและบริการ | ใครอยู่ในขอบเขต และได้รับบริการหรือยัง | คนตกหล่น นับซ้ำ นิยามสถานะ และการย้ายข้ามพื้นที่ |
| แบบทดสอบ / ภาระงาน | ผู้เรียนมีสมรรถนะตามเป้าหมายระดับใด | ความตรงของสิ่งที่วัด ความเทียบเคียง และการเข้าถึงเครื่องมือ |
| การสังเกตและเกณฑ์บรรยายระดับ | พฤติกรรมหรือคุณภาพงานเป็นอย่างไร | ผู้ประเมินอาจให้คะแนนต่างกัน ต้องฝึกและตรวจความสอดคล้อง |
| แบบสำรวจ | ผู้ตอบรับรู้ประสบการณ์หรืออุปสรรคอย่างไร | การไม่ตอบ ความเข้าใจคำถาม และผู้ตอบอาจไม่แทนทุกคน |
| สัมภาษณ์ / สนทนากลุ่ม | เหตุใดจึงเกิดปัญหา และควรปรับอะไร | ไม่ใช้สัดส่วนผู้ให้สัมภาษณ์แทนอัตราความชุกของทั้งจังหวัด |
| การติดตามก่อน–หลัง | กลุ่มเดิมเปลี่ยนแปลงอย่างไร | การเติบโต เหตุการณ์อื่น การฝึกทำข้อสอบ และผู้ติดตามไม่ครบอาจมีผล |

หากต้องการตอบว่าโครงการ “ทำให้เกิดผล” ต้องวางแบบประเมินที่ตรวจปัจจัยอื่นได้ เช่น มีกลุ่มเปรียบเทียบที่เหมาะสมหรือข้อมูลหลายช่วงเวลา พร้อมผู้เชี่ยวชาญช่วยตรวจข้อสมมติ ไม่สรุปเหตุจากคะแนนก่อน–หลังเพียงสองครั้ง

### 4. เกณฑ์ประเมิน: มีเหตุผลและใช้ตามบริบท

OECD (2021) เสนอหกมิติ ได้แก่ ความตรงกับความต้องการ ความสอดคล้องกับงานอื่น ประสิทธิผล ประสิทธิภาพ ผลกระทบ และความยั่งยืน ควรเลือกใช้ตามคำถามและบริบท แทนการบังคับใช้ทุกมิติด้วยน้ำหนักเท่ากัน

| มิติ | ตัวอย่างคำถามที่ผู้จัดทำเสนอ |
|---|---|
| ความตรงกับความต้องการ | บริการช่วยแก้อุปสรรคที่ผู้เรียนเผชิญจริงหรือไม่ |
| ความสอดคล้อง | โครงการเชื่อมภารกิจเดิมและลดงานซ้ำได้อย่างไร |
| ประสิทธิผล | ได้ผลตามเป้าหมายที่ตกลงและเข้าถึงกลุ่มเป้าหมายหรือไม่ |
| ประสิทธิภาพ | ทรัพยากรที่ใช้สัมพันธ์กับผลลัพธ์อย่างไร โดยไม่ลดคุณภาพหรือความเสมอภาค |
| ผลกระทบ | มีการเปลี่ยนแปลงที่สำคัญหรือผลที่ไม่คาดคิดอะไร และหลักฐานสาเหตุเพียงพอเพียงใด |
| ความยั่งยืน | ประโยชน์ยังคงอยู่หรือไม่เมื่อสิ้นสุดกิจกรรมหรือเงินสนับสนุน |

หากมีเกณฑ์ทางการที่ตรงกับงาน ให้ระบุชื่อ ฉบับ และเงื่อนไขการใช้ ส่วนเกณฑ์เสนอใหม่ให้หารือกับผู้เกี่ยวข้อง ตรวจค่าฐานและทรัพยากร บันทึกเหตุผล และกำหนดก่อนเห็นผล ไม่เปลี่ยนเกณฑ์ย้อนหลังเพื่อให้ผ่าน

### 5. ตัวอย่างเกณฑ์บรรยายคุณภาพการส่งต่อ

เกณฑ์นี้เป็น **ต้นแบบสำหรับทดลองและปรับเทียบ** ไม่ใช่มาตรฐานราชการ ไม่มีคะแนนรวมตัดสินจังหวัด

| ระดับเสนอ | หลักฐานที่ต้องเห็น |
|---|---|
| ยังประเมินไม่ได้ | ไม่มีข้อมูลที่เพียงพอต่อการตรวจรอยต่อ แยกจากระดับผลการดำเนินงาน |
| เริ่มดำเนินการ | มีคำขอส่งต่อ แต่ยังไม่มีการยืนยันรับช่วงจากปลายทาง |
| รับช่วงแล้ว | ปลายทางรับเรื่องและระบุผู้รับผิดชอบ แต่ยังไม่ยืนยันบริการ |
| ได้รับบริการ | มีหลักฐานว่าผู้เรียนได้รับบริการตามความจำเป็นและเวลาที่ตกลง |
| ติดตามและปรับบริการ | มีหลักฐานหลังรับบริการ รับฟังผู้เรียน และปรับเมื่อยังมีอุปสรรค |

ใช้กรณีตัวอย่างเดียวกันให้ผู้ประเมินอย่างน้อยสองคนทดลองตีความ แล้วอภิปรายจุดต่าง ปรับคำบรรยายและตัวอย่างหลักฐานก่อนใช้งานจริง ไม่ใช้ตัวเลขระดับเหล่านี้เป็นคะแนนเฉลี่ยโดยไม่ตรวจความหมายของช่วงคะแนน

### 6. คุณภาพข้อมูลและความเสมอภาค

เอกสารใน Projects พบข้อจำกัดเกี่ยวกับปี ขอบเขตประชากร การรวมร้อยละ และความหมายของตัวชี้วัดบริการ จึงมีหลักฐานเฉพาะว่าต้องปรับคุณภาพข้อมูลบางรายการ แต่ยังไม่ใช่ข้อยุติว่าระบบการประเมินทั้งหมดล้มเหลว อ่าน[บันทึกที่มาและข้อจำกัด](knowledge.html?article=source-notes)ประกอบ

ก่อนรวมข้อมูล ให้ใช้ประชากรและรอบเดียวกัน **อัตรารวม = ผลรวมตัวตั้ง ÷ ผลรวมตัวหาร × 100** ไม่บวกร้อยละข้ามหน่วยงาน การรวมต้องไม่ซ้ำคนและยังคงขอบเขตเดิม ถ้าขาดข้อมูล ให้รายงาน “ไม่มีข้อมูล” พร้อมความครบถ้วน ไม่แทนด้วยศูนย์ หากตัวตั้งมากกว่าตัวหาร ให้ตรวจนิยามก่อนรายงาน ไม่ตัดค่าที่เกิน 100 ให้เท่ากับ 100 เพื่อซ่อนปัญหา

การแยกข้อมูลตามอำเภอ ช่วงวัย สังกัด หรือกลุ่มที่ต้องการความช่วยเหลือช่วยตรวจความเสมอภาคได้ แต่ต้องพิจารณาขนาดกลุ่มและความเสี่ยงการระบุตัวบุคคล เว็บไซต์นี้แสดงข้อมูลรวม ไม่ใช้เป็นที่เก็บประวัติเด็กหรือบันทึกการช่วยเหลือรายบุคคล

### 7. รายงานให้เกิดการปรับปรุง

รายงานหนึ่งรอบควรตอบให้ครบ: คำถาม → ข้อมูลและช่วงเวลา → ผลที่พบ → ความครบถ้วนและข้อจำกัด → สิ่งที่ยังสรุปไม่ได้ → สิ่งที่ต้องปรับ → ผู้รับผิดชอบ → วันติดตาม หากข้อมูลและเป้าหมายยังไม่พร้อม ให้จัดสถานะ “รอค่าฐาน” หรือ “ยังประเมินไม่ได้” แยกจาก “ไม่บรรลุเป้าหมาย”

หน้าที่ข้อ 2.4–2.5 ของคณะทำงานขับเคลื่อนเป้าหมายการพัฒนาที่ยั่งยืนด้านการศึกษาระดับจังหวัด คือกำกับติดตามประเมิน และจัดเก็บวิเคราะห์ข้อมูล รวมถึงพัฒนวิธีเก็บตัวชี้วัดที่ยังไม่มีข้อมูล หน้านี้เป็นเครื่องมือประกอบการหารือ ไม่ใช่แบบรายงานของคณะทำงาน อ่าน [หน้าที่ตามคำสั่ง](implementation.html)

## เครื่องมือเรียนรู้เพิ่มเติม: แยกการรับรู้ตนเองออกจากความสามารถจริง

[แบบประเมินก่อน–หลังของ ayeduplan1](https://ayeduplan1.thamdee.com/assessment.html) มี 12 ข้อสำหรับสะท้อนความเข้าใจและความมั่นใจ โดยแยกข้อทัศนคติออกจากข้อด้านความสามารถที่ประเมินตนเอง เหมาะใช้ประกอบกิจกรรมเรียนรู้เรื่องการวางแผน แต่คะแนนเพิ่มไม่ยืนยันว่าผู้ตอบปฏิบัติงานได้ดีขึ้นจริง

ข้อเสนอการใช้ร่วมกับเครื่องมือในหน้านี้: ให้ผู้เข้าร่วมทำแบบสะท้อนตนเอง พร้อมจัดทำรายละเอียดตัวชี้วัดหนึ่งรายการ แล้วให้ผู้ตรวจใช้เกณฑ์ร่วมประเมินนิยาม สูตร และหลักฐาน แยกรายงานผลการรับรู้ตนเอง ผลงานที่ตรวจได้ และผู้ที่ติดตามไม่ครบ ไม่รวมเป็นคะแนนเดียวโดยอัตโนมัติ

[ตัวอย่างตรวจย้อนกลับของ ayeduplan2](https://ayeduplan2.thamdee.com/traceability.html) ใช้ฝึกตรวจเหตุผลของโครงการได้ ให้เพิ่มคำถามว่าหลักฐานใดเชื่อมกิจกรรมกับผลที่คาดหวัง และจุดใดยังต้องทดสอบ อ่าน[ความต่างของกรอบและสถานะข้อมูล](knowledge.html?article=related-planning)ก่อนนำตัวอย่างมาใช้
