## ใครทำอะไร และประสานกันอย่างไร

บทบาทด้านล่างเป็นคำอธิบายระดับภาพรวมจากเอกสารกฎหมายและแผนใน Projects ประกอบแหล่งทางการ ส่วนช่อง “แนวทางร่วมมือ” เป็นข้อเสนอสำหรับพัฒนา SDG 4 ไม่ใช่คำสั่งมอบหมาย การลงนาม การอนุมัติงบ และการเปิดเผยข้อมูลต้องตรวจอำนาจของผู้รับผิดชอบแต่ละกรณี

### คอลัมน์ที่มาข้อมูลในกรอบตัวชี้วัดประเทศ

<a id="data-owners"></a>

เอกสารสแกนตารางตัวชี้วัด SDG 4 ที่ได้รับจากสำนักงานศึกษาธิการจังหวัดเมื่อ 25 กันยายน 2569 มีคอลัมน์ «ที่มาข้อมูล» ใช้เป็น**คำถามตรวจอำนาจและช่องทางขอข้อมูล** ไม่ใช่คำสั่งมอบหมายให้หน่วยงานในตารางปฏิบัติงานให้จังหวัด และไม่ทำให้ ศธจ. เป็นเจ้าของข้อมูลนั้นโดยอัตโนมัติ การถอดตัวย่อจากภาพสแกนอาจคลาดเคลื่อน ให้ยึดสำเนาต้นฉบับ

| รหัสที่อ่านได้ | เจ้าของที่อ่านจากคอลัมน์ที่มาข้อมูล | คำถามตรวจก่อนขอหรือรายงาน |
|---|---|---|
| 4.1.1.1 | คะแนน NT · สพฐ. | จังหวัดขอร้อยละผู้ผ่านเกณฑ์ระดับจังหวัดได้จากช่องทางใด โดยไม่ขอผลรายบุคคล และเกณฑ์ «ระดับดีขึ้นไป» ตรงกับฉบับที่ใช้อยู่หรือไม่ |
| 4.1.1.2–4.1.1.3 | คะแนน O-NET · สทศ. | มีชุดข้อมูลจังหวัดที่เผยแพร่ได้หรือไม่ เกณฑ์ 50 คะแนนในตารางเป็นนิยามของเอกสารนี้ ไม่ใช่เป้าที่เว็บนี้ตั้งให้จังหวัด |
| 4.1.2.1 | สกศ. | อัตราสำเร็จใช้จำนวนนักเรียนชั้นสุดท้ายเทียบประชากรวัย 11 / 14 / 17 ปี คนละนิยามกับจำนวนออกกลางคันบนหน้าแรก |
| 4.2.1.1 | จปฐ. | พัฒนาการเด็ก 0–5 ปีอยู่ที่องค์กรปกครองส่วนท้องถิ่นชุดใด ครอบคลุมเด็กนอกศูนย์ อปท. หรือไม่ |
| 4.2.2.1 | สกศ. | สัดส่วนเด็ก 5 ปีในระดับก่อนประถมหรือสูงกว่า นับสถานศึกษาทุกสังกัดหรือเฉพาะชุดของเจ้าของตาราง |
| 4.3.1.1 / 4.3.2.1 | สกศ. | สัดส่วนสายอาชีวะใน ม.ปลาย และผู้สำเร็จอุดมศึกษาอายุ 25–34 ปี มีตารางจังหวัดล่าสุดปีใด |
| 4.4.1.1 | สสช. | การใช้อินเทอร์เน็ตอายุ 15 ปีขึ้นไปเป็นสถิติประชากร ไม่ใช่ทักษะ ICT ของผู้เรียนในสถานศึกษา |
| 4.5.1.1–4.5.2.1 | สกศ. | ดัชนีชาย/หญิงของการเข้าเรียนสุทธิและสำเร็จอุดมศึกษา ยังไม่มีบนเว็บนี้ ไม่แทนบริการผู้พิการ และข้อมูลบริการของศูนย์การศึกษาพิเศษประจำจังหวัดต้องถามจากศูนย์ฯ ไม่ใช่จากตารางนี้ |
| 4.6.1.1 | จปฐ. | การอ่านเขียนคิดเลขอายุ 15–59 ปีคนละชุดกับเครื่องมือประเมินในสถานศึกษา |
| 4.7.1.1–4.7.1.2 | สพฐ. | ร้อยละนักเรียน ม.ต้นที่ได้เรียนเนื้อหาสิ่งแวดล้อมและพลเมือง ไม่ใช่จำนวนทริปมรดก |
| 4.a.1.1–4.a.1.5 | ศทก.สป. | ร้อยละโรงเรียนที่มีคอมพิวเตอร์ ไฟฟ้า อินเทอร์เน็ต น้ำดื่ม และการล้างมือ ขอเป็นข้อมูลสถานศึกษาได้โดยไม่ระบุตัวผู้เรียนหรือไม่ |
| 4.a.2.1 | ศธจ. · ศธภ. | การรังแกมีนิยาม เครื่องมือ ขอบเขตสังกัด และวิธีปกป้องข้อมูลรายบุคคลหรือยัง |
| 4.b.1.1 | กต. · อว. | จำนวนทุน ODA เป็นตัวเลขประเทศ หากจะนับทุนผู้เรียนในจังหวัดต้องมีนิยามใหม่ |
| 4.c.1 / 4.c.2 | ศทก.สป. | สัดส่วนใบประกอบวิชาชีพและการเข้าอบรมไม่ใช่เกณฑ์อัตรากำลัง และไม่แทนหลักฐานการนำไปใช้ในชั้นเรียน |

ก่อนรับข้อมูลข้ามหน่วยงาน ให้ตกลงนิยาม วันนับ วิธีรับรอง และรูปแบบที่เผยแพร่ได้ หากไม่มีอำนาจหรือข้อตกลงที่เพียงพอ ให้เริ่มจากสถิติที่เปิดเผยแล้ว อ่านตารางถอดความทั้งชุดที่ [กรอบตัวชี้วัด SDG 4](knowledge.html?article=sdg4-national-indicators#owners)

<h3 id="special-ed">เส้นทางบริการการศึกษาสำหรับผู้พิการ</h3>

ผู้เรียนในความดูแลของศูนย์การศึกษาพิเศษประจำจังหวัดพระนครศรีอยุธยาเป็นส่วนหนึ่งของกลุ่มเป้าหมาย SDG 4 แต่ไม่ใช่ผู้พิการทั้งหมดในจังหวัด และไม่ใช่ผู้เรียนที่ถูกระบุความต้องการพิเศษทุกคน แยกเส้นทางศูนย์ฯ / เรียนรวมในสังกัดอื่น / ปฐมวัย / สาธารณสุขและพัฒนาสังคม ก่อนถามตัวเลข เว็บนี้ยัง**ไม่มีจำนวนผู้เรียนพิการ** และไม่บวกหัวจากศูนย์ฯ ลงยอดภาพระบบปี 2568 อ่านตารางกลุ่มและข้อห้ามที่ [บทความการศึกษาพิเศษ](knowledge.html?article=special-ed-21st#pathways)

### คณะทำงาน SDG ด้านการศึกษาของจังหวัด

จังหวัดมีคณะทำงานขับเคลื่อนเป้าหมายการพัฒนาที่ยั่งยืนด้านการศึกษาระดับจังหวัด ตามคำสั่งคณะกรรมการขับเคลื่อนเป้าหมายการพัฒนาที่ยั่งยืนด้านการศึกษา ที่ 32/2568 ลงวันที่ 31 มีนาคม 2568 ประธานคณะทำงานคือศึกษาธิการจังหวัด มีที่ปรึกษาจากหน่วยงานจังหวัด อุดมศึกษา ภาคเอกชน และมีคณะทำงานจากเขตพื้นที่ การศึกษาเอกชน อาชีวศึกษา การส่งเสริมการเรียนรู้ ศูนย์การศึกษาพิเศษประจำจังหวัด (สังกัดสำนักบริหารงานการศึกษาพิเศษ สพฐ.) และกลุ่มงานแผน/นิเทศ

องค์คณะนี้คนละชุดกับ กศจ. แม้คำสั่งจะกำหนดให้ผู้ทรงคุณวุฒิใน กศจ. และประธานอนุกรรมการที่เกี่ยวข้องร่วมเป็นคณะทำงาน หน้าที่ทั้งเจ็ดข้อ รายละเอียดกลุ่มตำแหน่ง และสำเนาไฟล์อยู่ที่ [หน้ากลไกขับเคลื่อน](implementation.html) และ [บทความคำสั่งแต่งตั้ง](knowledge.html?article=sdg4-working-group) ข้อเสนอว่าแต่ละข้อควรทำอย่างไรและผลงานที่ได้ควรเป็นอย่างไร อยู่ที่ [กรณีศึกษาการดำเนินงานรายข้อ](knowledge.html?article=sdg4-duty-proposals)

### แยกความสัมพันธ์สี่แบบ

**การสังกัด/กำกับดูแล** ใช้เมื่อมีฐานทางการรองรับ **การประสานนโยบาย** ใช้เชื่อมเป้าหมายและแผน **การร่วมดำเนินงาน** ต้องระบุเจ้าภาพและข้อตกลง ส่วน **การสนับสนุนทรัพยากร** ต้องระบุสิ่งที่ให้ ระยะเวลา และข้อจำกัด มหาวิทยาลัย อปท. และสถานศึกษาต่างสังกัดไม่ควรถูกวาดให้เป็นผู้ใต้บังคับบัญชาของ ศธจ. ทั้งหมด

### ข้อตกลงทำงานร่วมที่เสนอ

ทุกกิจกรรมควรมีผู้รับผิดชอบหลักหนึ่งราย ผู้ร่วมดำเนินงาน ผู้ให้คำปรึกษา และผู้รับทราบ ระบุทั้งชื่อหน่วยงานและตำแหน่งผู้ประสาน โดยไม่จำเป็นต้องเผยแพร่เบอร์ส่วนบุคคล ผู้ประสานไม่จำเป็นต้องเป็นผู้อนุมัติงบหรือผู้ควบคุมข้อมูล

ก่อนรับข้อมูลข้ามหน่วยงาน ให้ตกลงนิยาม วันนับ วิธีรับรอง และรูปแบบข้อมูลรวม หากไม่มีอำนาจหรือข้อตกลงที่เพียงพอ ให้เริ่มจากข้อมูลสถิติที่เผยแพร่ได้ ไม่ถือว่าการเป็นภาคีทำให้เข้าถึงข้อมูลรายบุคคลได้โดยอัตโนมัติ
