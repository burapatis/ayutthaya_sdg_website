## ร่วมสร้างสังคมแห่งการเรียนรู้

พื้นที่นี้เตรียมไว้สำหรับแลกเปลี่ยนประสบการณ์ ข้อเสนอเชิงนโยบาย และตัวอย่างการทำงานเกี่ยวกับ SDG 4 จังหวัดพระนครศรีอยุธยา ยินดีรับฟังทั้งมุมมองของผู้เรียน ครอบครัว ครู หน่วยงาน และประชาชนผู้สนใจ

### ประเด็นชวนแลกเปลี่ยน

- อุปสรรคใดทำให้คนในพื้นที่เข้าไม่ถึงการเรียนรู้ และบริการแบบใดช่วยได้
- โครงการหรือกิจกรรมใดมีบทเรียนที่ควรแบ่งปัน พร้อมหลักฐานที่ตรวจสอบได้
- ตัวชี้วัดใดสะท้อนคุณภาพและความเสมอภาคได้ดี และข้อมูลใดยังขาด

### แนวทางร่วมสนทนา

สื่อสารด้วยความเคารพ วิจารณ์แนวคิดโดยไม่โจมตีบุคคล ระบุแหล่งข้อมูลเมื่อกล่าวถึงสถิติหรือข้อเท็จจริง และไม่เผยแพร่ชื่อ ภาพ เลขประจำตัว หรือรายละเอียดที่ย้อนระบุตัวผู้เรียนได้ หากเป็นเรื่องช่วยเหลือรายบุคคล ให้ติดต่อหน่วยงานผู้รับผิดชอบผ่านช่องทางที่เหมาะสม

ความคิดเห็นที่ส่งผ่าน Giscus จะจัดเก็บใน GitHub Discussions ของผู้จัดทำและอาจเปิดอ่านได้สาธารณะ การแก้ไขหรือลบความเห็นใช้ความสามารถของ GitHub และการดูแลของเจ้าของพื้นที่สนทนา ระบบจะเริ่มเชื่อมต่อเมื่อกดเปิดพื้นที่สนทนาหลังผู้จัดทำตั้งค่าบริการแล้ว
